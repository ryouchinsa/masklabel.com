Segment anything. Label it in a click.

MaskLabel is an instance segmentation annotation tool for Mac. SAM3 runs on Apple silicon through MLX, so masks appear as fast as you click.

Download on the Mac App StoreSee features

Requires a Mac with Apple silicon. Works with COCO and YOLO datasets.

Built for labeling segmentation masks

Click to segment

Add points or drag a box and SAM3 returns the mask. Refine an existing mask by clicking to add or remove regions.

Find Objects with AI

Describe what to look for and review the results with a confidence slider, then save the ones you want.

Pixels and polygon masks

Edit with a brush, polygon points or the SAM tab. Simplify polygons to the point count you need, with full undo and redo.

COCO and YOLO

Import and export both formats. Train, valid and test splits are kept, and same-named images in different splits stay separate.

Made for large datasets

Thousands of class names, hundreds of masks per image, and a fast image browser with thumbnails and split editing.

Your shortcuts

Every action can get its own shortcut. Export them as JSON to use the same setup on several Macs.

Pricing

Free mode

Label with SAM3, edit Polygon and Pixels masks, use the Image Browser, and import and export COCO and YOLO, with no limit on images or masks. Every new install starts with a 30-day trial of everything, including Pro.

Pro

Adds the AI tools that label many objects at once: Find Objects on the current image and across a folder, Refine Boxes, and Convert Boxes in one step.
