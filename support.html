Support

Email support@masklabel.com. For bug reports, include your macOS version, your Mac model, the MaskLabel version, and the steps that led to the problem.

What do I need to run MaskLabel?

A Mac with Apple silicon. SAM3 runs through MLX, which requires it.

Which dataset formats are supported?

COCO and YOLO, for both import and export.

How do I restore my purchase?

Open MaskLabel and use the restore option in the purchase screen. You need to be signed in to the Apple ID used for the purchase.

Where can I find the shortcuts and help?

Read the Help page, which is the same as the Help window in the app. You can change any shortcut in Customize Shortcuts.

How do I clear cached data?

The Help window lists the cache files MaskLabel creates and how to delete them.
